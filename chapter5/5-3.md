# Copilot Team Standards

## Task Format
All tasks must include:
- Task
- Constraints
- Verification

## Planning
- Use Plan Mode for multi-step or multi-file tasks
- Review the plan before allowing execution

## Security Rules
- Do not log sensitive data
- Do not expose environment variables
- Do not modify authentication logic without approval

## Scope Control
- Do not refactor unrelated files
- Modify only what is necessary

## Verification
- Always test the result before accepting changes
- Confirm no unintended behavior was introduced
